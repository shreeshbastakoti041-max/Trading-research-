SHREESH BASTAKOTI PORTFOLIO WEBSITE
===================================

WHAT'S IN THIS FOLDER
  index.html    the page (don't need to touch)
  styles.css    the look (don't need to touch)
  site.js       builds the page (don't need to touch)
  content.js    ALL your text, reports, research and contact  <-- edit this one
  reports/      your PDF reports
  img/          report cover images
  photos/       put your own pictures here


PUT IT ONLINE FREE WITH GITHUB PAGES (about 10 minutes)
  1. Make a free account at github.com. Your username becomes your web
     address, e.g. username "shreeshb" -> https://shreeshb.github.io
  2. Click "+" (top right) -> "New repository".
     Name it exactly:  YOURUSERNAME.github.io
     Set it to Public, then click "Create repository".
  3. On the new repository page click "uploading an existing file".
     Unzip this folder on your computer, then drag EVERYTHING inside it
     (the files and the reports, img, photos folders) into the browser.
     Click "Commit changes".
  4. Go to Settings -> Pages. Under "Branch" choose "main" and "/ (root)",
     then Save.
  5. Wait 1-2 minutes, then open https://YOURUSERNAME.github.io

  Faster alternative: go to app.netlify.com/drop and drag the unzipped
  folder onto the page. You get a link right away (make a free account
  to keep it and rename it).


UPDATE THE SITE LATER (all in the browser on GitHub)
  Edit text:      open content.js -> pencil icon -> change -> Commit changes
  Add a report:   open the reports folder -> Add file -> Upload files ->
                  drop the PDF -> Commit. Then add a block for it in
                  content.js (instructions are at the top of that file).
  Remove a report: delete its block in content.js (and the PDF if you like).
  Add photos:     upload into the photos folder, then add a line in the
                  photos list in content.js.
  Changes show up on the site within a minute or two.
